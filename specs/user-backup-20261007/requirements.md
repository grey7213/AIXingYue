# 用户本地备份与导入

用户要求核实当前合并修复，并开放个人数据下载备份及导入，降低只依赖服务器恢复点的风险。

范围：在“我的 → 设置”提供备份入口，下载带版本标记的 ZIP；包含当前账号人设、自己创作的角色及历史版本/草稿、云端聊天及候选回复、会话设置/变量/记忆。导入先校验并显示数量，再由用户执行恢复；新建私有副本，重映射引用，重复导入相同包不重复创建。人设恢复单独勾选。保留现有数据。

不导出密码、token、站点模型凭据、其他人的角色提示词；余额、支付、排名、互动奖励不能靠导入改写。外部 URL 内容与尚未同步到服务器的设备草稿不承诺已保存，界面和清单明确范围。媒体资源需列明实际收录/缺失，不允许静默截断。

验收：身份隔离、无敏感字段、版本与消息往返一致、外部角色权限不提升、损坏包/超限包拒绝且无部分写入、重复导入幂等；真实桌面/390px 页面、手机文件下载及导入、生产服务健康与原修复保留。

# 惑梦验证码邮件视觉更新

## 需求与验收

注册验证码邮件改为有品牌辨识度的「入梦邀请函」：品牌页眉、欢迎语、突出且可连续复制的六位验证码、有效期、安全提示和官网入口。兼顾 320px 手机与桌面邮箱，图片关闭后仍能完整阅读。共享模板同时覆盖中文/英文、注册/密码重置，重置邮件不得出现注册引导。

## 设计与范围

- 小范围邮件模板更新，复用已有 Python EmailMessage multipart/alternative、Resend HTTPS 与 SMTP/sendmail 链路，不引入邮件框架或第三方依赖，无需另行开源选型。
- 在 `tools/ai_fengyue_local_server.py` 中抽取纯函数 `build_verification_email`，返回 subject、text、html；原发送函数仅调用模板。
- 560px 流式 table 布局、内联样式、紫色深色页眉、白色正文、淡紫验证码卡片；纯文本品牌，不依赖外链图片、字体、脚本、渐变或 flex/grid。媒体查询仅作小屏增强，删除 style 标签后仍可读。
- 验证码保持一个连续文本节点，保留前导零；文案说明首次申请后 10 分钟有效，重发不会延期，与当前复用规则一致。
- 不改变注册/重置接口、数据库、限流、验证码生成/核销逻辑，不发送未经指定收件人的测试邮件。
- 部署前核对线上后端与修改前本地 SHA-256 相同；单文件备份、定向更新后端，避免覆盖其他线上变更。
- 线上进程复核发现 `APP_BRAND` 与 `SMTP_FROM` 显示名称仍为旧品牌。备份环境文件后仅更新正式品牌及发件人显示名称，保留原发信地址与其余配置；修正部署器的默认品牌以免新部署复发。

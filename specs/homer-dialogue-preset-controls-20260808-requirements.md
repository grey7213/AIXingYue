# 惑梦对话预设可见性与操作收敛 Requirements

日期：2026-08-08

## 目标

收敛生产 SillyTavern 对话页的移动端扩展和快捷操作，并将右下角预设面板改为服务端权威的“角色卡预设 + 官方公开条目”控制面板。

## 功能范围

1. 停用手机弹窗扩展
   - 固定保留 `st-yuzi-phone` 源码和版本，不删除扩展目录。
   - 默认设置、存量用户设置和会话扩展快照均强制将 `third-party/st-yuzi-phone` 置为停用。
   - 对话启动时不得加载该扩展的 JS/CSS 资源或出现其手机弹窗。

2. 移除全局快捷操作坞
   - 删除右下角“续写 / 重写 / 下回续”全局操作坞。
   - 保留每条适用消息绑定的“回溯 / 续写 / 重写 / 下回 / 前后 Swipe”。
   - 逐消息动作继续以当前消息稳定索引/标识为目标，并保留日志、云同步和生成锁。

3. 角色卡预设条目
   - 右下角预设面板显示当前会话锁定角色版本所绑定的 `card_prompt_preset` 全部条目。
   - 只返回条目 ID、名称、角色、位置、顺序、默认/当前状态、覆盖及锁定状态，不返回正文。
   - 有正文、进入顺序表且非 Marker 的条目允许当前会话开关；结构 Marker、空正文或未进顺序表条目只读展示。

4. 官方全局 Prompt 条目
   - 后台为每条官方 Prompt 增加“向用户显示并允许开关”选项，权威字段为 `user_toggleable`。
   - 新导入及历史未配置条目默认 `false`，不得因升级自动公开。
   - 用户面板只显示当前会话实际选中的官方 Prompt 预设中 `user_toggleable=true` 的条目。
   - 即使管理员勾选，Marker、空正文或未进顺序表条目仍只读锁定；其他公开条目可按当前会话开关。

5. 权限与隔离
   - 开关写入 `conversation_preset_overrides`，角色卡使用 `card_prompt`，官方 Prompt 使用 `global_prompt`。
   - 服务端必须拒绝伪造 ID、跨角色版本 ID、隐藏官方条目、错误预设 ID和非会话所有者请求。
   - 读取历史覆盖时按当前角色版本和当前会话所选官方预设重新过滤，旧隐藏覆盖不得继续生效。
   - 站点必需反扒世界书不出现在该面板，继续强制启用且不可关闭。
   - 会话 A 的覆盖不得影响会话 B、其他用户、角色卡源数据或官方预设 JSON。

6. 真实生成链路
   - 普通 OpenAI/Anthropic 聊天和 SillyTavern bridge 生成均必须应用角色卡/官方条目的当前会话覆盖。
   - SillyTavern 传入的消息不能覆盖掉服务端组装的卡片预设、官方预设、必需反扒世界书、记忆或结构化数据库提示。

## 验收标准

- Python/Node 静态检查和 Git 差异检查通过。
- 后端夹具覆盖公开/隐藏/伪造/跨卡/历史覆盖过滤、正文不泄露、A/B 会话隔离和 provider payload 哨兵。
- 原版 SillyTavern 桌面 1440px 与移动 390px 真实 Chromium 验证：全局操作坞不存在，逐消息动作仍有效，预设分组/锁定/切换正确，无横向溢出，console/page error 为 0。
- `st-yuzi-phone` 保持目录存在但处于 disabled，且验收期间其资源请求为 0。
- 反扒 ZIP 与站点权威世界书哈希一致；runtime 配置和预设面板不返回反扒正文。
- 本轮不构建 APK。

## 非目标

- 不删除 `st-yuzi-phone` 扩展源码，不改变其他三项公共扩展。
- 不移除每条消息绑定的续写、重写、下回、回溯和 Swipe。
- 不允许普通用户查看 Prompt 正文、世界书正文或修改官方预设源数据。
- 不恢复角色卡版本选择功能。

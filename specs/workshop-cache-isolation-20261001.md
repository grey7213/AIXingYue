# 创作工坊私有作品缓存隔离修复

## 要求与验收

修复 `2418241` 引入的工坊账号缓存污染。私有作品必须属于本次服务端确认的身份，迟到请求不能污染其他账号；丢弃旧版不可信工坊缓存。新建/导入入口不等待资料加载。用户已指定使用本机 Pixel 6 模拟器验证实际 APK WebView。

## 设计

- 仅修改工坊初始化/刷新与其缓存迁移；其他页面缓存不清除。
- 每轮刷新先确认 profile，再读取对应账号的新版工坊缓存和刷新私有作品；账号确认失败不查询私有作品。
- 用刷新代次与身份比较阻止迟到结果；重新显示、账号清理、销毁均使旧代次失效，并合并重叠刷新。
- 工坊缓存迁移到独立新版 scope，删除旧 scope 下所有账号缓存，避免复用已经串号的数据。
- 更新工坊 HTML 与依赖缓存版本，定向备份发布；APK 内置资源不会随网站更新，必须构建 1.17.4（282）。先在独立 debug 包验证隔离夹具，再以原包名/签名覆盖升级正式包，保留已有账号与会话数据。

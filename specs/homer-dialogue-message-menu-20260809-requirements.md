# 惑梦对话消息长按菜单 Requirements

日期：2026-08-09

## 目标

保留 `E:\酒馆开发\对话界面UI原型-开发交接包-网站弹窗视觉统一-20260809.zip` 原文件不变，将原版 SillyTavern 对话消息上的常驻元数据行、顶部按钮和底部逐消息操作条收敛为按消息气泡长按/右键打开的网站风格菜单。

## 功能范围

1. 清理消息常驻控件
   - 普通浏览状态不显示角色名、版本/时间、问号、更多、编辑等消息头行。
   - 不显示 Homer 常驻“回溯 / 续写 / 重写 / 下回 / Swipe”操作条。
   - 不显示原版 SillyTavern 左右 Swipe 箭头和候选计数。
   - 消息正文必须释放上述控件占用的空间；此前已隐藏的消息头像继续保持隐藏。

2. 长按/右键消息菜单
   - 触屏或鼠标按住消息气泡约 `520ms` 打开菜单；移动超过 `12px`、抬起或取消指针时取消触发，避免滚动误触。
   - 桌面支持右键；键盘支持 Context Menu 键和 `Shift+F10`。
   - 点击遮罩、关闭按钮或 Escape 关闭菜单。
   - 桌面菜单靠近目标气泡并限制在视口内；`390px` 手机使用安全区内底部弹层。

3. 动作集合
   - 用户输入：复制、编辑、回溯、删除。
   - 角色回复：复制、编辑、回溯、续写、重写、下回续写、上一候选、下一候选、删除。
   - 菜单可显示“用户输入 / 角色回复”和当前候选序号，但不得恢复角色名、版本和时间常驻展示。
   - 编辑继续复用 SillyTavern 原生编辑器；编辑期间只显示必要的保存/取消控制。

4. 精确消息绑定
   - 打开菜单时记录目标消息的当前 `mesid` 与稳定 Homer 消息标识。
   - 执行动作前重新解析目标；消息索引变化时按稳定标识寻找，找不到则拒绝操作，禁止退化成默认操作最后一条消息。
   - 对较早消息执行续写、重写、下回或候选切换时，沿用现有确认与时间线截断规则。
   - 云端回溯和单条删除必须同时更新当前 SillyTavern 页面、Homer 云端存档和逐消息日志。

5. 生成与安全边界
   - 生成中允许复制，但禁用编辑、回溯、续写、重写、下回、候选切换和删除。
   - 系统消息不提供菜单。
   - 不改变模型桥、卡片脚本、RoleplayHub 沙箱、Prompt/世界书权限、`st-yuzi-phone` 停用状态或 APK。

## 验收标准

- 原型 ZIP 大小仍为 `4,078,721` bytes，SHA-256 仍为 `699D71E86FDD2420262DCF41B03413460B3D30BF6B030C9212795747E332DE11`。
- Node/Python 静态检查、项目 selftest 和 `git diff --check` 通过。
- 原版 SillyTavern 1.18.0 在 `1440×900` 与 `390×844` 真实 Chromium 中：
  - 消息头、常驻操作条、原生 Swipe 箭头/计数均不可见；
  - 长按用户消息只编辑准确目标消息；
  - 角色消息菜单的续写、重写、下回和候选切换真实生效；
  - 回溯从长按菜单执行并实时同步页面与云端；
  - 手机底部弹层不溢出，无 console/page/network error，Yuzi 资源请求为 0。
- 本轮不构建 APK。

- 不修改或提交 `Tavo_主题效果_14G5y(1).thm`。

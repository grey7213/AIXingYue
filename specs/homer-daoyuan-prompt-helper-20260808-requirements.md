# 惑梦《道渊》提示词助手与消息头像 Requirements

日期：2026-08-08

## 目标

1. 隐藏生产 SillyTavern 对话消息左上角的角色/用户头像，使消息正文与逐消息操作栏自然占用释放后的空间。
2. 让《道渊》角色卡中名为“提示词助手”的随卡脚本在惑梦 Web 对话 runtime 中按预期显示悬浮窗。
3. 优先修复 Web/runtime；只有在浏览器安全边界内无法兼容且有明确证据时，才把软件/APK 端作为后续方案。本轮不构建 APK。

## 功能范围

- 头像只从聊天消息行移除；不得隐藏顶部角色信息、角色列表、抽屉、扩展管理页或卡内 HTML 自己绘制的头像。
- 消息正文、逐消息回溯/续写/重写/下回/Swipe 操作必须保持可见、可点击，并在桌面和 390px 移动端无残留空列。
- 解析《道渊》PNG 中的 Character Card 元数据，确认“提示词助手”的真实存储字段、启用状态、依赖和执行时机。
- 导入/同步链路必须无损保留该脚本；runtime 只能执行当前会话锁定角色版本中明确启用的随卡脚本。
- 沿用固定 SillyTavern 1.18.0 与 JS-Slash-Runner 4.8.19 的角色级脚本机制，不新增普通用户扩展安装权限。账号 Cookie 继续保持 HttpOnly，runtime 不下发 Bearer Token、后台权限或模型 Key；卡片已有的固定远程依赖按原脚本执行并纳入浏览器请求/错误验收。
- 不恢复已删除的全局“续写/重写/下回续”操作坞，不启用 `st-yuzi-phone`，不泄露 Prompt、反扒世界书或脚本正文到普通用户 API/log。

## 验收标准

- 《道渊》夹具能在隔离原版 SillyTavern/Homer runtime 中稳定复现并修复；“提示词助手”悬浮入口可见且基础展开/关闭交互有效。
- 1440×900 与 390×844 Chromium：消息头像不可见、正文无空列、逐消息操作仍工作、悬浮窗不被 overflow/z-index 遮挡、无横向溢出。
- console error、page error 为 0；除卡片中已固定声明的脚本 CDN 外无意外公网请求；`st-yuzi-phone` JS/CSS 请求仍为 0。
- Python/Node 静态检查、相关 selftest 和 Git diff 检查通过。
- 生产部署后 backend/dialogue/Nginx active，8008/8091 health 与公网对话入口正常，关键文件哈希与本地一致。

## 非目标

- 不重做整套对话 UI，不恢复旧 TavoJS 主聊天界面。
- 不开放任意第三方脚本安装或同源父页面访问。
- 不修改《道渊》角色设定、Prompt 正文、世界书正文或版本选择逻辑。
- 不构建、签名或发布 APK。
